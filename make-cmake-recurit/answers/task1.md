# Task 1：从 C 源码到可执行文件

请用自己的语言简要说明下面几个阶段分别做了什么：

1. 预处理
运行gcc -E hello.c -0 hello.i -E代表只进行预处理，会将头文件展开，替换宏定义，删除注释等，
生成的.i文件是一个纯文本文件，里面只有c代码。
2. 编译
执行gcc -S hello.i -o hello.s ，-S表示执行驳岸一到汇编语言，编译器会检查代码文法，如果有
错会报错,r如果无错，会将C语言翻译成对应CPU架构的汇编语言由高级语言变成汇编语言，为汇编阶
段做准备
3. 汇编
执行gcc -c hello.s -o hello.o,-c表示执行汇编，将汇编代码翻译成机器能直接理解的二进制指令，
生成的.o文件是一个二进制文件，但是还不能直接运行，因为还没有接入外部函数。
4. 链接
执行gcc hello.o -o hello链接器将.o文件与标准库链接，外部函数以二进制的形式存储在标准库中
链接器将其搬运到占位符处，生成可执行文件

建议控制在 300～500 字，不需要展开复杂细节。
